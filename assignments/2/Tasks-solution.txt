### Part B: Group Management 

4. **Create two groups**:

   - `developers` :
         ahmed@ahmed:~$ sudo groupadd developers
         ahmed@ahmed:~$ tail -4 /etc/group
         alice:x:1001:
         bob:x:1002:
         charlie:x:984:
         developers:x:1003:

   - `project-team` :
         ahmed@ahmed:~$ sudo addgroup project-team
         info: Selecting GID from range 1000 to 59999 ...
         info: Adding group `project-team' (GID 1004) ...


5. **Add users to groups**:

   - >>  ahmed@ahmed:~$ sudo usermod -aG developers,project-team alice
         ahmed@ahmed:~$ id alice
         uid=1001(alice) gid=1001(alice) groups=1001(alice),1003(developers),1004(project-team)

   - >>  ahmed@ahmed:~$ sudo usermod -aG developers bob
         ahmed@ahmed:~$ id bob
         uid=1002(bob) gid=1002(bob) groups=1002(bob),1003(developers)

   - >>  ahmed@ahmed:~$ sudo usermod -g developers alice
         ahmed@ahmed:~$ id alice
         uid=1001(alice) gid=1003(developers) groups=1003(developers),1004(project-team)


6. **Verify group memberships**:

   - >>  ahmed@ahmed:~$ groups alice
         alice : developers project-team

   - >>  ahmed@ahmed:~$ id bob
         uid=1002(bob) gid=1002(bob) groups=1002(bob),1003(developers)




### Part C: File Permissions and Ownership (25 points)

7. **Create test files and directories**:

      -     ahmed@ahmed:/$ mkdir tmp/lab1_test
      -     ahmed@ahmed:/$ cat > tmp/lab1_test/data.txt
            best practicies
            ahmed
            ^C
      -     ahmed@ahmed:/$ touch tmp/lab1_test/script.sh
            ahmed@ahmed:/$ ls tmp/lab1_test/
            data.txt  script.sh


8. **Set permissions using symbolic notation**:

      -     ahmed@ahmed:/$ chmod g-w tmp/lab1_test/data.txt
      -     ahmed@ahmed:/$ chmod a+x tmp/lab1_test/script.sh
      -     ahmed@ahmed:/$ chmod g-w tmp/lab1_test/script.sh
            ahmed@ahmed:/$ ls -l tmp/lab1_test/
            total 4
            -rw-r--r-- 1 ahmed ahmed 22 Oct 14 13:07 data.txt
            -rwxr-xr-x 1 ahmed ahmed  0 Oct 14 13:09 script.sh


9. **Change ownership**:

      -     ahmed@ahmed:/$ sudo chown alice:developers tmp/lab1_test/data.txt
      -     ahmed@ahmed:/$ sudo chown -R bob:project-team tmp/lab1_test/
